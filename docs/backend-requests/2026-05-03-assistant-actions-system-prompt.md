# Backend request — Assistant action protocol in system_prompt

**Дата:** 2026-05-03
**Контекст:** новая страница `/app/assistant` (см. spec `docs/superpowers/specs/2026-05-02-llm-chat-format-design.md`).
**Просьба:** добавить блок ниже в дефолтный `system_prompt` для воркспейс-чатов. Фронт ничего не дописывает — у тебя промпт уже большой, и единый источник правды на бэке нам обоим удобнее.

## Текст для добавления в system_prompt

> Когда в обсуждении появляется конкретная идея для поста (тема + общее описание), в самом конце ответа добавь блок:
>
> ```
> ========SYSTEM======
> {"actions":[{"type":"save_as_idea","title":"...","description":"..."}]}
> ```
>
> Допустимые типы:
> - `save_as_idea` — пользователь сохранит идею в календарь;
> - `open_in_editor` — пользователь откроет идею в редакторе сразу.
>
> Можно вернуть массив (несколько идей за раз — каждая отдельным элементом). Если идеи нет — блок не пиши.
> Маркер `========SYSTEM======` — ровно эта строка, без отступов и без вариаций. JSON одной строкой, без обёрток ```json.

## Как фронт его обрабатывает

- Парсер ищет первое вхождение `========SYSTEM======`, всё что до него — видимый текст ответа, всё что после — JSON с actions.
- Битый JSON / неизвестные типы → actions игнорируются, маркер всё равно режется из видимого текста (юзер не видит мусор).
- Под последним сообщением ассистента, если actions есть, рендерятся карточки с кнопкой «+ Идея» / «📝 В редактор».

## Editor-чат

Этот же маркер может прилететь и в editor-чате (внутри `/app/editor`) — там фронт тоже его режет, но карточки не рендерит (пользователь уже в редакторе, кнопки бессмысленны). То есть инструкцию можно класть в общий system_prompt без вилок per-context.

## Если нужно условно

Если хочется отрубать инструкцию для editor-чата — пробрось от фронта флаг типа `context: 'global' | 'editor'` в `sendWorkspaceMessage`, и подключай блок только при `global`. Но это nice-to-have, не блокер.
